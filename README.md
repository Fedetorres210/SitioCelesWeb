# BCR · Tu primera tarjeta de crédito

Sitio educativo para jóvenes sobre la tarjeta de crédito del BCR: qué es, cómo funciona, mitos y realidades, y tips para un uso responsable.

Diseño aprobado en Figma: https://www.figma.com/design/HkhsZjre4tzk7p975HA3Zg

## Estructura

```
index.html        Todo el contenido del sitio
css/styles.css    Estilos (mobile first; desktop desde 900px)
js/main.js        Menú móvil, tarjetas de mitos que se voltean y carrusel
assets/img/       Tucán, tarjeta y logo
```

Es un sitio estático: no necesita instalar nada ni compilar.

## Verlo en tu computadora

```bash
python3 -m http.server 8000
```

Y abrí http://localhost:8000
